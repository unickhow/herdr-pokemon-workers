# Pokémon Workers（繁體中文）

這是一個 [Herdr](https://herdr.dev) mod：每個 agent 都是一隻御三家寶可夢。視窗最上方有一條橫列，每個 space 一格；
按下 **Campus** 會打開一個園區，所有 agent 都住在裡面：工作的坐在桌前、閒置的在公園晃、累了的睡在墊子上、做完的在公告欄前等你、
被卡住的在服務台求救。

- agent 是御三家的最終型態，它的子代理是同一組的第一型態。涵蓋 9 個世代、草火水共 27 組。
- 新 agent 建立時隨機分配一組，之後固定不變。
- 狀態：工作＝埋頭忙碌；閒置＝站著，超過 90 秒沒動靜就蜷起來睡覺並飄出 Z；完成＝一直跳到你去看它；被卡住＝紅色「!」。
- 點動物會跳到對應的 agent。
- 五個場景（禪庭園、草原、溫室、雪景、海灘），園區會依電腦時間變暗、變暖。

安裝、會碰到哪些東西（網路、`curl`、檔案）與授權請看 [README.md](README.md) 和 [NOTICE.md](NOTICE.md)。
寶可夢圖檔**不在此專案裡**，第一次用到時才從 PMD SpriteCollab 下載到你自己的電腦，並在 Credits 中列出作者。
